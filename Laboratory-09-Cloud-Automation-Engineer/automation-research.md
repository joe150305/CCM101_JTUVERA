# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that run in sequence. The `#!/bin/bash` line is called the shebang, and it tells the operating system to use Bash to execute the script.

## 2. Variables

Variables store information such as folder paths and filenames so that values can be reused. For example, `$BACKUP_DIR` allows us to change the backup location without editing every command that uses it.

## 3. Cron Job

A cron job is a Linux task scheduled to run automatically at a specified time. It is useful in cloud operations because it can automate repetitive activities such as backups and system maintenance.
