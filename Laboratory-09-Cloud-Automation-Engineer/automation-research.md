# Automation Research

## 1. Bash Script

A Bash script is a text file that contains Linux commands that execute in sequence. The `#!/bin/bash` line is called the shebang, and it tells the operating system to use the Bash shell to run the script.

## 2. Variables

Variables store information such as folder paths, filenames, and timestamps so they can be reused in a script. For example, `$BACKUP_DIR` allows us to change the backup location in one place instead of modifying every command that uses it.

## 3. Cron Job

A cron job is a scheduled task in Linux that automatically runs a command or script at a specified time. It is essential in cloud operations because it automates repetitive tasks such as backups, system maintenance, and log cleanup without requiring a person to run commands manually.
