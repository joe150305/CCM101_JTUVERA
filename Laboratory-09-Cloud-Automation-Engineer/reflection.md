# Mission 9 Reflection: The Cloud Automation Engineer

Throughout this laboratory activity, I learned that automation is important when managing cloud environments. When administrators manage hundreds of servers, performing tasks manually takes too much time and increases the possibility of human error. Automation allows repetitive activities, such as backups and system maintenance, to run consistently and efficiently.

However, automation also has potential dangers. A script containing a destructive command or an incorrect file path could delete important information. If that script runs on 1,000 servers, the damage could affect a large part of an organization's infrastructure. To prevent this, administrators should review and test scripts before deployment, use appropriate permissions, monitor execution, and maintain backups and recovery plans.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands and variables to perform tasks step by step. Docker Compose YAML defines the services, networks, and configurations required to run a multi-container application. Bash focuses on executing commands, while Docker Compose focuses on defining an application's environment.

Looking back at Laboratories 1 through 9, my understanding of Cloud Computing has developed from learning basic cloud concepts to exploring infrastructure, containers, data storage, deployment, operations, security, and automation. Each laboratory introduced skills that helped me understand the different responsibilities of a cloud engineer. I also learned the importance of documentation, testing, and troubleshooting.

The role I enjoyed most was the Cloud Automation Engineer because it combines scripting and problem-solving to reduce repetitive work. Creating a backup script and scheduling it with Cron helped me understand how a few commands can automate an important administrative task. This activity showed me that cloud computing is not only about deploying systems but also about making them reliable, efficient, and secure. In the future, I want to improve my scripting skills and explore more automation tools.
