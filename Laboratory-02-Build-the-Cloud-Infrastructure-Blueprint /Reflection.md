# Mission Reflection

This laboratory activity gave me a better understanding of the important components that make up a cloud infrastructure. I learned that different resources must work together for a cloud environment to function properly. Among these components, **compute resources** are especially important because they provide the processing capability required to run programs, applications, services, and different workloads.

I also gained practical experience using Linux in a cloud-based environment. Through the KillerCoda Playground, I used different Linux commands to examine information about the operating system, processor, CPU cores, memory, disk storage, mounted file systems, hostname, and IP addresses. Performing these commands helped me understand how administrators can inspect and monitor the resources available on a Linux cloud server.

Another important lesson from this activity was the value of proper technical documentation. Documentation helps organize important information about a system and makes it easier for developers, administrators, and engineers to understand the infrastructure. It can also help when identifying problems, monitoring resources, performing maintenance, and managing cloud systems.

During this laboratory activity, I also learned more about the similarities and differences between the major cloud providers: **Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform**. I discovered that these platforms offer similar core services for computing, storage, networking, and access management, although the names and specific features of their services may be different.

This activity also helped me develop my skills in **Markdown, technical writing, cloud infrastructure research, Linux commands, and GitHub repository management**. Creating organized reports, comparison tables, screenshots, and documentation improved my ability to present technical information clearly.

Overall, this laboratory provided useful hands-on experience with both Linux and cloud computing concepts. It helped me understand how cloud infrastructure resources work together and allowed me to add organized technical documentation and project outputs to my GitHub Cloud Computing Portfolio.
