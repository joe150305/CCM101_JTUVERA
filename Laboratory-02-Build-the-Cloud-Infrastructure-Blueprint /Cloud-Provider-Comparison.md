# Cloud Provider Comparison

## Checkpoint 4 – Exploring Major Cloud Providers

This activity examines three of the leading cloud computing platforms: **Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)**. Each provider offers services for computing, data storage, networking, and identity management.

## Comparison of Cloud Services

| Cloud Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Compute Services** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage Services** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking Services** | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| **Identity Management** | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

Although the names of the services are different, the three providers offer similar fundamental cloud capabilities. AWS uses EC2 and S3, Azure provides Virtual Machines and Blob Storage, while Google Cloud offers Compute Engine and Cloud Storage.

## Guide Questions

### 1. Which cloud provider has the largest variety of services?

**Amazon Web Services (AWS)** is known for offering a large selection of cloud services. These include computing, storage, databases, networking, security, artificial intelligence, and data analytics.

### 2. Which cloud platform is suitable for organizations that use Microsoft technologies?

**Microsoft Azure** is often a suitable option for organizations that already use Microsoft products. It provides strong integration with services and technologies from the Microsoft ecosystem.

### 3. Which provider is strongly associated with AI, machine learning, and Kubernetes?

**Google Cloud Platform (GCP)** is widely recognized for its cloud technologies related to artificial intelligence and machine learning. It is also known for strong support for Kubernetes and container-based applications.

### 4. What common features do the three providers share?

AWS, Azure, and Google Cloud all provide essential cloud infrastructure services. Each platform includes services for **computing, storage, networking, and identity and access management**. While their service names and implementations are different, their main purpose is similar: providing scalable resources and services through the cloud.
