# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage using MinIO. The mission scenario involves a client developing a photo-sharing application that needs a reliable and scalable location for storing millions of user-uploaded images.

MinIO was deployed as a containerized object storage server using Docker. A bucket named `client-photos` was created and a test file was uploaded to verify that the object storage system was working.

## Objectives

- Understand the differences between Block Storage, File Storage, and Object Storage.
- Identify the appropriate storage type for user-uploaded images.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console through port 9001.
- Create an object storage bucket.
- Upload a test file to the bucket.
- Document the technical deployment process.
- Provide screenshots as evidence of the completed tasks.
