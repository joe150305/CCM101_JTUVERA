# Laboratory 04 - Cloud-Native Engineer

## Mission Overview

This laboratory activity focuses on cloud-native computing and containerization. It introduces the differences between Virtual Machines and Containers and provides hands-on experience using Docker. In this activity, I deployed an Nginx web server inside a Docker container and practiced managing its container lifecycle.

## Objectives

- Understand the differences between Virtual Machines and Containers.
- Verify that Docker is installed and running.
- Pull an Nginx image from Docker Hub.
- Run an Nginx web server using Docker.
- Configure port mapping using Docker.
- Test the Nginx web server using curl.
- Manage the lifecycle of a Docker container.
- Document the laboratory activity using Markdown.
- Organize and maintain my cloud computing portfolio on GitHub.
