
# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides virtual machines, storage, databases, networking, identity, analytics, artificial intelligence, developer tools, and enterprise services. Azure was introduced in 2010.

## Global Infrastructure

Azure organizes its infrastructure into geographies, regions, and availability zones. An Azure region is a geographic area containing datacenters, while availability zones are separate groups of datacenters within a region.

Availability zones are designed to improve the availability and resilience of applications.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. It provides access to virtual machines, storage, databases, networking, identity, monitoring, and billing.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers for Linux and Windows workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, backups, and application files.

### 3. Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate securely through private networking, subnets, routing, and security controls.

### 4. Microsoft Entra ID

Microsoft Entra ID provides cloud identity and access management. It can integrate with Microsoft services and organizational identity systems.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft 365, Windows Server, Active Directory, SQL Server, and other Microsoft technologies.
2. **Enterprise Features** – Azure provides services designed for security, governance, compliance, and enterprise environments.
3. **Hybrid Cloud Support** – Azure supports environments that combine on-premises infrastructure and cloud services.

## Typical Enterprise Use Cases

Azure is commonly used for:

- Windows Server workloads
- Microsoft 365 integration
- Hybrid cloud infrastructure
- Enterprise application hosting
- SQL Server workloads
- Identity and access management
- Business applications
- Artificial intelligence and analytics
