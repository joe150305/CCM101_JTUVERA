
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform operated by Amazon. It provides computing, storage, databases, networking, security, analytics, artificial intelligence, and many other cloud services. AWS was publicly launched in 2006.

## Global Infrastructure

AWS organizes its infrastructure into Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This structure helps organizations create applications with high availability and fault tolerance.

AWS also provides edge infrastructure for applications that require lower network latency.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources. Users can access services such as EC2, S3, IAM, RDS, networking, monitoring, and billing through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can run Linux, Windows, and other operating systems.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, backups, application data, images, videos, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking resources for creating isolated cloud networks and controlling communication between resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) manages authentication and authorization for AWS resources.

## Three Advantages

1. **Wide Service Selection** – AWS provides a large variety of cloud services for different workloads.
2. **Global Infrastructure** – AWS has infrastructure distributed across many geographic locations.
3. **Scalability** – AWS resources can be adjusted according to application requirements.

## Typical Enterprise Use Cases

AWS is commonly used for:

- Web and mobile application hosting
- Data storage and backup
- E-commerce systems
- Enterprise databases
- Disaster recovery
- Data analytics
- Artificial intelligence and machine learning
- Containerized applications
