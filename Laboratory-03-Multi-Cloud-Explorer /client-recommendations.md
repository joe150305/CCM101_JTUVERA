# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for a startup with a limited budget and expectations for rapid growth. The company can begin with small cloud resources and scale them as the application gains users. AWS provides many services that can support a mobile application without requiring the company to build its own physical infrastructure. The wide selection of services also gives the startup room to expand its architecture later.

### Possible Services

- Amazon EC2 – application servers
- Amazon S3 – file and media storage
- Amazon RDS – relational database
- Amazon CloudFront – content delivery

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and supports hybrid cloud scenarios. The university can gradually migrate selected services instead of moving everything at once. Microsoft Entra ID can also help manage identity and access across cloud resources.

### Possible Services

- Azure Virtual Machines – Windows or Linux workloads
- Microsoft Entra ID – identity and access management
- Azure SQL Database – managed SQL database
- Azure Blob Storage – cloud file/object storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is a strong choice for an AI research company because it provides services and infrastructure designed for machine learning, data analytics, and high-performance computing. Google Cloud supports GPU and other accelerator-based workloads through its compute services. The company can also use managed AI/ML and data services to develop and operate research applications.

### Possible Services

- Compute Engine – high-performance virtual machines
- Google Cloud AI/ML services – machine learning development and deployment
- Cloud Storage – datasets and research files
- BigQuery – large-scale data analytics

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for a multinational e-commerce company because it provides global infrastructure and services for scalable, highly available applications. The company can distribute workloads across multiple Availability Zones and Regions. AWS also provides load balancing, automatic scaling, databases, storage, and content delivery services. This architecture can help support changing traffic levels and global customers.

### Possible Services

- Amazon EC2 – application servers
- Elastic Load Balancing – distributes incoming traffic
- EC2 Auto Scaling – automatically adjusts compute capacity
- Amazon RDS – managed relational database
- Amazon CloudFront – global content delivery

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, flexible scaling, and many options for starting small |
| Enterprise Organization | AWS | Mature enterprise services and a broad cloud ecosystem |
| Microsoft Environment | Microsoft Azure | Strong integration with Windows Server, Microsoft 365, and Active Directory |
| AI / Machine Learning | Google Cloud | Strong AI/ML and data capabilities with accelerator-based computing |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides a managed Kubernetes platform |
| Global Web Application | AWS | Large global infrastructure and services for high availability and scaling |

## Conclusion

The best cloud provider depends on the client's technical and business requirements. There is no single provider that is always the best choice. AWS is a strong general-purpose and global option, Azure is especially suitable for Microsoft environments, and Google Cloud is a strong option for AI, data, and Kubernetes workloads.
