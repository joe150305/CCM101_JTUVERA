# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for a startup with a limited budget and expectations for rapid growth. The company can start with smaller cloud resources and increase them as the number of users grows. AWS provides many services that can support a mobile application without requiring physical servers. Its wide selection of services also allows the startup to expand its system in the future.

### Possible Services

- Amazon EC2 – application servers
- Amazon S3 – file and media storage
- Amazon RDS – relational database
- Amazon CloudFront – content delivery

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and supports hybrid cloud environments. The university can migrate selected services gradually instead of moving the entire infrastructure at once. Microsoft Entra ID can also help manage identity and access.

### Possible Services

- Azure Virtual Machines – Windows or Linux workloads
- Microsoft Entra ID – identity and access management
- Azure SQL Database – managed SQL database
- Azure Blob Storage – cloud object storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is a strong choice for an AI research company because it provides services and infrastructure for artificial intelligence, machine learning, data analytics, and high-performance computing. Google Cloud supports GPU and other accelerator-based workloads. The company can use these resources to develop and operate AI applications.

### Possible Services

- Compute Engine – high-performance virtual machines
- Google Cloud AI/ML services – machine learning development
- Cloud Storage – datasets and research files
- BigQuery – large-scale data analytics

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for a multinational e-commerce company because it provides global infrastructure and services for scalable and highly available applications. The company can distribute workloads across multiple Availability Zones and Regions. AWS also provides load balancing, automatic scaling, databases, storage, and content delivery services. These services can help the company handle changing traffic levels and global customers.

### Possible Services

- Amazon EC2 – application servers
- Elastic Load Balancing – distributes incoming traffic
- EC2 Auto Scaling – automatically adjusts compute capacity
- Amazon RDS – managed relational database
- Amazon CloudFront – global content delivery

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, flexible scaling, and options for starting small |
| Enterprise Organization | AWS | Mature enterprise services and a broad cloud ecosystem |
| Microsoft Environment | Microsoft Azure | Strong integration with Microsoft technologies |
| AI / Machine Learning | Google Cloud | Strong AI/ML and data capabilities |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides managed Kubernetes |
| Global Web Application | AWS | Global infrastructure and services for high availability and scaling |

## Conclusion

The best cloud provider depends on the client's technical and business requirements. There is no single provider that is always the best choice. AWS is a strong general-purpose and global option, Azure is especially suitable for Microsoft environments, and Google Cloud is a strong option for AI, data, and Kubernetes workloads.
