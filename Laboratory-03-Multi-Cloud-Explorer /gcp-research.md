
# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides compute, storage, databases, networking, data analytics, artificial intelligence, machine learning, and container services. Google Cloud was launched in 2008.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Regions are geographic locations, while zones are deployment areas within regions. Google Cloud also uses Google's global network to connect its cloud infrastructure.

Google Cloud provides services such as Compute Engine, Cloud Storage, Google Kubernetes Engine, Cloud SQL, and Virtual Private Cloud.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources. It provides access to Compute Engine, Cloud Storage, networking, IAM, Kubernetes, databases, monitoring, and billing.

## Four Core Services

### 1. Compute Engine

Compute Engine provides configurable virtual machines that run on Google's infrastructure.

### 2. Cloud Storage

Cloud Storage provides scalable object storage for application files, backups, media, and other data.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy and manage containerized applications.

### 4. Cloud IAM

Cloud Identity and Access Management (IAM) controls who can access Google Cloud resources and what actions they can perform.

## Three Advantages

1. **AI and Data Capabilities** – Google Cloud provides strong services for artificial intelligence, machine learning, and data analytics.
2. **Kubernetes Support** – Google Kubernetes Engine provides a managed Kubernetes environment.
3. **Global Network** – Google's global network supports applications that require reliable and low-latency connectivity.

## Typical Enterprise Use Cases

Google Cloud is commonly used for:

- Artificial intelligence and machine learning
- Big data and analytics
- Kubernetes and containerized applications
- Web and mobile application hosting
- Data warehousing
- Application modernization
- Global applications
- Research and high-performance computing
