# Reflection

This laboratory activity helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. I learned that the three cloud providers offer similar basic services, but each platform has different strengths.

I learned that AWS has a broad range of cloud services and is suitable for many types of organizations. Azure is a strong option for organizations that already use Microsoft technologies. Google Cloud is a strong choice for Artificial Intelligence, data analytics, and Kubernetes workloads.

The client recommendation activity helped me understand that choosing a cloud provider should depend on business requirements rather than popularity. For example, a university using Windows Server and Microsoft 365 would benefit from Azure, while an AI research company may benefit from Google Cloud.

The Linux investigation also helped me connect traditional server administration with cloud computing. By using commands such as `cat /etc/os-release`, `lscpu`, `free -h`, and `df -h`, I learned how to inspect a server's operating system, CPU, memory, and disk space.

Overall, this activity improved my understanding of multi-cloud computing. I learned that cloud decisions should consider cost, scalability, availability, existing technologies, performance, and the specific needs of an organization.
