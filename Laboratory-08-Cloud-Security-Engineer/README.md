
# Laboratory 08 – Cloud Security Engineer

## Mission Overview
This laboratory focuses on securing an Ubuntu server using UFW (Uncomplicated Firewall). The mission includes deploying a web application, auditing network access, and configuring firewall rules.

## Objectives
- Understand the Principle of Least Privilege.
- Identify a server's attack surface.
- Configure a Default Deny firewall policy.
- Allow SSH and TCP port 8080.
- Document security configurations and evidence.

## Commands Executed
Commands will be documented after completing the practical tasks.

## Skills Learned
- Linux server administration
- Docker container deployment
- Firewall configuration using UFW
- Network port management
- Technical documentation using Markdown
